{# Kanban board: stage columns of cards that can be dragged from one column to another, plus a narrow "dock" for end states (for example Done / Archived). Layout is decided by the board's own width, not the screen's: - wide: every column side by side, dock on the right, no sideways scroll. - narrow: a strip of tabs with counts, one column shown at a time. - no JavaScript: columns simply stack, one under the other. Moving a card is always possible without a mouse: give every card a menu (`actions`) with "Move to" items. Dragging is a shortcut on top of that. Usage: {% from "kdui/components/kanban.html" import kanban, kanban_column, kanban_dock, kanban_card, kanban_row %} {% call kanban(id="board", move_url="/items/{id}/move", csrf_token=csrf_token(), cols=4, dock=true, tabs=[{"id": "new", "label": "New", "count": 2, "color": "var(--chart-1)"}, ...], active="new") %} {% call kanban_column(id="new", label="New", count=2, total="$600", color="var(--chart-1)") %} {{ kanban_card(id=1, title="Website redesign", href="/items/1", subtitle="Alex Martin", note="Review draft · due today", tone="warning", value="$300", aside="Close Oct 10", actions=[...]) }} {% endcall %} {% call kanban_dock() %} {% call kanban_column(id="done", label="Done", count=1, total="$300", compact=true) %} {{ kanban_row(id=8, title="Logo refresh", href="/items/8", value="$300", actions=[...]) }} {% endcall %} {% endcall %} {% endcall %} kanban params: id {string} Unique id. move_url {string} Optional. URL that receives a POST when a card is dropped in another column; "{id}" is replaced by the card id. The POST carries csrf_token, stage (the column id) and position (end of the column). The page reloads afterwards, so totals and anything the server changes along the way stay correct. Leave empty to turn dragging off. csrf_token {string} Sent with the move POST. cols {int} Columns outside the dock. Default 4. dock {bool} True when a kanban_dock() follows the columns. tabs {list} Narrow layout: [{id, label, short, count, color}], one per column, in order. (short is an optional shorter label for the tab.) active {string} Column id shown first in the narrow layout. label {string} Accessible name of the board. kanban_column params: id, label, count {int}, total {string, optional}, color {string, optional CSS colour}, empty {string} text shown when count is 0, compact {bool} for dock columns. The body (the cards) comes from the call block and is only rendered when count > 0. kanban_card params: id, title, href, subtitle, note (the next step), tone ("danger" | "warning" | "muted"), value, aside, actions (action_menu items, needs at least one), draggable {bool}.
