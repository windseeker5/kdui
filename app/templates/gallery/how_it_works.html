What is Flask Starter?

Flask Starter is a UI toolbox for Flask developers. You focus on your idea, Python code, and database. It provides the polished visual foundation.

Your finished project remains a normal server-rendered Flask and Jinja application. You do not need React, Vue, TypeScript, Node.js, or npm.

Step 1

Get the Flask Starter toolbox

Do this once on a new computer.

cd ~/projects
git clone https://github.com/windseeker5/kdui.git flask-shadcn-starter
cd flask-shadcn-starter

Already cloned it? Update it before creating a new app:

cd ~/projects/flask-shadcn-starter
git pull

This folder is your reusable toolbox. Keep it separate from the applications you create.

Step 2

Create a to-do application

Run the generator from inside the Flask Starter toolbox.

python scripts/kdui.py new ../my-todo
projects/
├── flask-shadcn-starter/   ← reusable toolbox
└── my-todo/                ← your new Flask application

The generator copies only the small Flask foundation, finished styling, and files needed by the example. It does not copy the gallery, dashboard, CRM, or toolbox development files.

Step 3

Run your new application

cd ../my-todo
python -m venv .venv
source .venv/bin/activate       # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python wsgi.py

Open http://127.0.0.1:5005. You can add, complete, and delete tasks.

{{ alert(message="No npm install is required. Flask Starter already copied the compiled CSS and browser JavaScript into your application.", title="Python is enough") }}

Step 4

Start building your idea

The generated example is deliberately small.

app/routes.py

Your Flask routes and application behavior.

templates/todos/index.html

Your server-rendered Jinja page.

templates/components/

Reusable, good-looking UI pieces.

The example stores tasks in memory so it is easy to understand. Replace that list in app/routes.py with your preferred database when ready.

Optional

Add another UI component

Run these commands from the Flask Starter toolbox.

# See what is available
python scripts/kdui.py list components

# Copy one component into your application
python scripts/kdui.py add component card --target ../my-todo

The tool copies the component and any support files it requires. Your application receives only what it needs.

See available components

Why is npm not required?

Application developers: Flask Starter gives you finished CSS and JavaScript. You work with Python, Flask, Jinja, and your database.

Flask Starter maintainers: npm is used inside this toolbox to compile Tailwind CSS and update Basecoat before those finished files are distributed.
