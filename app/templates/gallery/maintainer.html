Repository responsibility

KD UI is an installable component library and showroom. It is not an application generator or a sample CRM.

Basecoat supplies visual primitives. KD UI supplies namespaced Jinja components, larger reusable patterns, compiled assets, and documentation.

Develop locally

python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
npm ci
python wsgi.py --port 5005

The editable Python installation exposes src/kdui to the showroom. npm is needed only by KD UI maintainers.

Add or improve UI

Build from a real need, then remove application assumptions.

  1. Check Basecoat and the existing gallery first.
  2. Put a small macro in src/kdui/templates/kdui/components/.
  3. Put a reusable composition in src/kdui/templates/kdui/patterns/.
  4. Use namespaced imports beginning with kdui/.
  5. Add a live gallery example and copyable usage.
  6. Rebuild CSS if any Tailwind class changes.

Update Basecoat

Treat dependency upgrades as focused changes.

npm outdated basecoat-css
npm install basecoat-css@latest
npm run build

Test and release

npm run build
pytest
git diff --check
git status

Release a tagged version. Consumer applications should pin that version and upgrade deliberately.
