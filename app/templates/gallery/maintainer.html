Improve a component

This is the normal workflow.

  1. Edit the macro in src/kdui/templates/kdui/components/ or patterns/.
  2. Update its example in the UI gallery.
  3. Check it in light, dark, desktop, and mobile views.
  4. Run pytest.

If you changed Tailwind classes, also run npm run build:css.

Update Basecoat

Do this occasionally and separately from component work.

npm outdated basecoat-css
npm install basecoat-css@latest
pytest

npm install automatically synchronizes Basecoat and rebuilds the CSS. Review the gallery afterward, especially interactive components.

Release a version

Only when other projects are ready to receive the changes.

  1. Update the KD UI version.
  2. Run npm run build:css and pytest.
  3. Merge the pull request.
  4. Create and push a matching Git tag.
First-time setup 
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
npm ci
python wsgi.py --port 5005
